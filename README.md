# Pooper Scooper AI Skills Library

Free, practical instruction files that help Claude and other AI tools sound more like an experienced pooper scooper operator.

This repo is packaged as a Claude Code plugin so you can install the full skill library in one step.

## Quick start

Add the marketplace:

```bash
/plugin marketplace add maptheday/pooper-scooper-skills
```

Install the plugin package:

```bash
/plugin install pooper-scooper-skills@pooper-scooper-marketplace
```

After that, Claude can use the skills for customer conversations, pricing, team onboarding, and growth.

## What’s inside

- Customer communication: cancellation-handler, complaint-response, firing-a-customer, objection-handling, price-increase-notice, seasonal-communication, win-back-message, yard-quote-estimator
- Team operations: first-day-script, performance-conversation, pooper-scooper-job-post
- Growth: negative-review-response, neighborhood-outreach, referral-ask, review-request, upsell-message
- Pricing: late-payment-followup, pricing-confidence, service-agreement-language, yard-quote-estimator

The packaged skill files live under [plugins/pooper-scooper-skills/skills](plugins/pooper-scooper-skills/skills), and the marketplace metadata is in [.claude-plugin/marketplace.json](.claude-plugin/marketplace.json).

## Manual use (optional)

If you want to use a skill without the plugin, open the relevant file in [plugins/pooper-scooper-skills/skills](plugins/pooper-scooper-skills/skills) and upload it to Claude or another AI tool.
